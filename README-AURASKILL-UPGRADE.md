# AuraSkill Tech Premium Upgrade

This ZIP contains the upgraded AuraSkill Tech website based on your Lovable export.

## What was improved
- Premium 3D-style hero with sharper brand positioning
- Upgraded navbar with corporate mega menus
- More unique homepage layout and conversion-focused sections
- Stronger AI automation, website, chatbot, dashboard and internship messaging
- Global 0px card/input/button radius style while keeping 3D orb visuals intact
- Updated contact email to `team@auraskilltech.com`
- Indian-market friendly pricing labels on the Services page
- Footer redesigned with sharper brand identity

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Upload to GitHub and connect the repository to Vercel or Cloudflare Pages.
